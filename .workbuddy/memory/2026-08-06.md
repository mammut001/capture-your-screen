# 2026-08-06 — 12-round iteration on capture-your-screen

## Branch
`feature/12-round-iteration` (commit fb8f6f0)

## Summary
Completed 12 rounds of feature/UX improvements across the macOS screenshot app and CLI helper.

### R1 — Menu Bar Quick Capture Shortcut
- `MenuBarPanels.swift`: Added `.keyboardShortcut(.space, modifiers: [])` to the "Take Screenshot" button so users can press Space while the panel is open to immediately start a capture.

### R2 — CLI Helper Version & Error Improvements
- `CLIArguments.swift`: Added `--version` flag parsing and `version` field.
- `HelperRunner.swift`: Added `--version` handler that returns `helper_version` in JSON. Enhanced error JSON with `hint` fields. Added `file_size_bytes` to successful capture output. Improved error handling with `ScreenCaptureError` specific catch block.

### R3 — History Search/Filter
- `MenuBarPanels.swift`: Added a search bar above history list (magnifyingglass icon + TextField + clear button). Filters by filename or display time.
- `MenuBarViewModel.swift`: Added `historyRows(matching:)` method that filters `HistoryListRow` by query string.

### R4 — Annotation Editor Shortcut Help Overlay
- `AnnotationEditorView.swift`: Added `ShortcutHintBar` and `ShortcutHintItem` views displayed as a floating overlay at the bottom of the action bar. Shows ⌘Z/⇧⌘Z/⌫/Space/⌘S/Esc hints.

### R5 — File Size Display in History
- `ScreenshotHistoryItem.swift`: Added `fileSize: Int64?` field and `formattedFileSize` computed property.
- `ScreenshotRecord+toHistoryItem`: Reads file size from disk attributes.
- `MenuBarPanels.swift`: Displays formatted file size in each history card next to the timestamp.

### R6 — Configurable Calendar First Weekday
- `MenuBarViewModel.swift`: Added `@AppStorage("firstWeekdayPreference")` (Int, default 1 = Sunday).
- `SettingsView` (`MenuBarPanels.swift`): Added Calendar GroupBox with segmented Picker for Sunday/Monday.

### R7 — Batch Delete in History
- `MenuBarViewModel.swift`: Added `isBatchMode`, `selectedForBatch: Set<String>`, `toggleBatchMode()`, `toggleSelection(_:)`, `batchDelete()`.
- `MenuBarPanels.swift`: Added "Batch" button in footer. History cards show selection checkmarks in batch mode. Added bottom bar with "Cancel" / "Delete Selected" buttons when items are selected.

### R8 — Image Format Conversion Option
- `MenuBarViewModel.swift`: Added `SaveFormat` enum (png/jpeg) and `@AppStorage("saveFormatPreference")`.
- `SettingsView`: Added Image Format GroupBox with PNG/JPEG segmented Picker.

### R9 — History Export to JSON
- `MenuBarViewModel.swift`: Added `exportHistoryToJSON()` using `NSSavePanel` with `.json` content type. Exports paths, filenames, dates, and file sizes.
- `SettingsView`: Added Export GroupBox with "Export History to JSON…" button.

### R10 — Smooth Spring Animations
- `OverlayWindow.swift`: Added fade-in (0.18s) and fade-out (0.12s) `NSAnimationContext` animations on open/close.
- `PostCaptureActionWindow.swift`: Added fade-out (0.15s) animation on dismiss.

### R11 — Menu Bar Capture Count Badge
- `capture_your_screenApp.swift` (`AppDelegate`): Added `updateMenuBarBadge()` that counts today's screenshots and updates the status item title. Called after history refresh.

### R12 — Pin/Favorite Screenshots
- `MenuBarViewModel.swift`: Added `@AppStorage("pinnedScreenshotIDs")` persisted as comma-separated string. Added `togglePin(_:)` and `isPinned(_:)`.
- `MenuBarPanels.swift`: History cards show pin.fill icon in top-right when pinned. Context menu includes Pin/Unpin action.
